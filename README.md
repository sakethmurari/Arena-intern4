E-commerce Sales Analysis
Project Overview

This project analyzes e-commerce sales data using Python.
The aim is to understand sales performance and trends.
The project follows a complete data analysis process.

Objectives
Load and clean sales data
Analyze total sales and products
Create charts using Python
Write simple insights

Tools Used
Python
Pandas
Matplotlib
NumPy

Run the program
python main.py

Charts Created
Bar chart – Sales by product
Line chart – Sales trend
